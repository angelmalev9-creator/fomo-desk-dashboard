# FOMO бюро — табло

Статично табло за частното PAPER бюро. Хоства се на GitHub Pages. Данните се четат от таен GitHub Gist, чийто идентификатор се подава само в адреса (`#g=…`) и се пази в браузъра. Идентификаторът не е записан в това хранилище.

Страницата не съдържа ключове, токени или chat id. Обновява се около веднъж на 75 секунди.

Линковете към монети са директни към FOMO и не се съкращават.
