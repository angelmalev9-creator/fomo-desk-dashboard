# FOMO бюро — табло

Статично табло за частното PAPER бюро. Хоства се на GitHub Pages. Данните се четат от таен GitHub Gist, чийто идентификатор се подава само в адреса (`#g=…`) и се пази в браузъра. Идентификаторът не е записан в това хранилище.

Изгледи: **Табло** (баланс, жива крива, агенти, позиции, сделки), **Повторение** (сделките от сесията една по една с брояч на P&L и класация) и **Обобщение** (статистика на сесията).

`#demo=1` в адреса показва измислени примерни данни с голям надпис „DEMO данни“. Нормалният изглед показва само истинските данни от бюрото.

Червеният бутон „Спри и продай всичко“ само отваря Telegram бота. Там продажбата иска потвърждение с бутон и засяга само PAPER позиции. Страницата не може да пише в бюрото.

Страницата не съдържа ключове, токени или chat id. Линковете към монети идват от бюрото, директни към FOMO, без съкращаване.
